# Bad USB Using Arduino

## Overview
Bad USB Using Arduino is an educational cybersecurity project demonstrating USB Human Interface Device (HID) emulation using a compatible Arduino board. It explores how programmable USB devices can automate keyboard input and why organizations should consider the security implications of untrusted USB devices.

## Objectives
- Understand USB HID emulation.
- Explore Arduino-based keyboard automation.
- Implement button-controlled demonstration modes.
- Use EEPROM to store a selected demonstration mode.
- Implement LED indicators for device status.
- Understand USB security risks and preventive measures.

## Hardware and Technologies
- **Microcontroller:** Arduino board compatible with USB HID
- **Programming language:** C/C++ (Arduino)
- **Libraries:** Keyboard, EEPROM
- **Components:** Push button and LED

## Project Features
- Multiple selectable demonstration modes.
- Button-based mode selection.
- EEPROM-based mode storage.
- LED status indication.
- USB HID keyboard emulation.

## Safety and Ethics
This project is intended for educational use and authorized security testing only. Use it exclusively on devices you own or have explicit permission to test. Public releases should exclude credential collection, clipboard exfiltration, persistence mechanisms, destructive behavior, and unauthorized account or file modifications.

## Learning Outcomes
This project demonstrates embedded programming, USB HID concepts, hardware input handling, EEPROM storage, and awareness of USB-based security threats.
